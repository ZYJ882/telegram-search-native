# Telegram Search Native v1.3.1：时间序列搜索列表

v1.3.1 移除搜索结果页的 # 与字母分组标题，搜索结果统一按消息时间倒序显示。

## 功能更新

| 项目 | 说明 |
|---|---|
| 移除分组标题 | 不再显示 # 或字母标题，避免与实际浏览顺序产生误解。 |
| 时间序列 | 搜索结果按消息时间从新到旧排列。 |
| 滑块定位 | 右侧垂直滑块按当前时间序列的位置进行快速定位。 |
| 性能优化 | 移除会话名称分组与额外排序，搜索结果列表仅维护时间顺序。 |
| 多选兼容 | 长按多选、全选、批量本机收藏和批量删除仍适用于当前时间序列结果。 |

## 使用方式

在搜索页输入关键词后，结果会按时间顺序显示。通过右侧垂直滑块可快速定位到列表的较早或较晚位置；不再出现 # 或字母分组标签。
