# Telegram Search Native v0.9.0：搜索页字母索引与快速定位

v0.9.0 为搜索结果页增加按会话名称分组的右侧字母索引，便于在本地消息较多时快速定位。

## 功能更新

| 功能 | 说明 |
|---|---|
| 会话首字母分组 | 搜索结果按会话名称的英文字母首字母分组显示。 |
| 未识别分组 | 非英文字母开头、数字、符号及空名称统一归入 `#` 分组。 |
| 右侧索引条 | 搜索结果页右侧显示 `#–Z` 索引；有数据的分组使用正常颜色显示，无数据分组以弱化颜色显示。 |
| 点击定位 | 点击有效字母可平滑定位到对应分组。 |
| 上下拖动 | 在索引条内上下滑动时，会自动选择距离手指位置最近的有效分组并快速定位。 |
| 当前分组提示 | 当前可见分组在右侧索引条中高亮显示。 |

## 使用方式

在**搜索**页面执行查询后，结果将按会话名称的首字母分组。点击右侧字母，或在右侧索引条内上下拖动，即可跳转到目标分组。名称不以英文字母开头的会话显示在 `#` 分组中。
