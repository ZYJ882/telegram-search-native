# Telegram Search Native v1.4.0：多页面滑块定位

v1.4.0 将右侧垂直滑块快速定位扩展到“收藏”和“同步”页面，使较长的本机收藏列表与会话选择列表也可直接按位置快速跳转。

## 功能更新

| 页面 | 更新内容 |
|---|---|
| 本机收藏 | 收藏数量超过一条时，右侧显示垂直滑块；拖动可按列表位置快速跳转到目标收藏消息。 |
| 选择会话并同步 | 当前可见会话数量超过一条且未在同步时，右侧显示垂直滑块；可对已选置顶会话及搜索结果组成的列表快速定位。 |
| 滑动反馈 | 拖动期间显示列表百分比浮层；正常滚动时，滑块位置会跟随当前浏览位置更新。 |
| 布局适配 | 列表为滑块预留右侧空间，避免滑块遮挡消息卡片、会话名称和勾选控件。 |

## 使用方式

在“收藏”页保存多条本机收藏，或在“同步”页加载多个会话后，可直接按住屏幕右侧的圆形滑块上下拖动。滑块会按当前列表的相对位置跳转，适合快速浏览较长的列表。

同步进行时，会话勾选操作保持锁定，右侧滑块也会暂时隐藏；同步完成或停止后，仍可继续使用滑块浏览会话列表。

## 兼容性

本次更新只调整本地界面的列表定位方式，不改变 Telegram 登录、历史同步、消息索引或本机收藏数据。覆盖安装新版本可保留已有的本地数据与登录状态。
