# Telegram Search Native v1.2.0：搜索索引管理

v1.2.0 在设置页新增明确的搜索索引管理入口，支持删除全部本地索引或按会话删除对应索引。

## 功能更新

| 项目 | 说明 |
|---|---|
| 搜索索引管理 | 设置页显示已索引消息数、会话数和本机收藏数。 |
| 删除全部索引 | 一次删除当前设备中的全部同步消息、搜索索引和本机收藏。 |
| 按会话删除 | 展开会话索引列表后，可查看每个会话的已索引消息数与本机收藏数，并单独删除。 |
| 二次确认 | 删除全部索引和删除单会话索引均需要确认，避免误操作。 |
| 即时刷新 | 删除后搜索结果、收藏、会话统计和索引管理列表会立即刷新。 |
| 本地范围 | 所有删除操作仅影响本应用在当前设备保存的数据，不会删除 Telegram 账号中的原始消息、聊天记录或 Saved Messages。 |

## 使用方式

进入 **设置 → 搜索索引管理**。可选择“删除全部搜索索引”，或点击“按会话删除索引”展开会话列表，再点击目标会话右侧的删除按钮。确认后操作立即生效。
