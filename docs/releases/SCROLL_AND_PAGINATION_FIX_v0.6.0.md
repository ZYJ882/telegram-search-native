# Telegram Search Native v0.6.0：详情浏览与历史分页稳定性

v0.6.0 优化消息详情页的长内容浏览体验，并改进历史同步的分页游标处理。

## 功能更新

| 模块 | 更新内容 |
|---|---|
| 消息详情滚动 | 详情页采用独立垂直滚动容器，可完整浏览长文本与操作入口。 |
| 文本与操作可达性 | 复制、收藏和 Telegram 跳转等操作始终位于可滚动页面内。 |
| 历史分页游标 | 后续历史请求使用 `offset = -1` 从当前游标之前继续读取。 |
| 消息去重 | 每页按消息 ID 去重，避免重叠页面产生重复索引。 |
| 短页处理 | TDLib 返回少于页面上限的消息时，继续根据游标状态判断是否读取后续历史。 |
| 重复页保护 | 连续重复页触发有限重试与明确的同步状态提示。 |

## 同步机制

TDLib 在非零 `from_message_id` 与 `offset = 0` 的组合下可能从游标消息本身开始返回。v0.6.0 将后续请求调整为从游标之前继续读取，并保留消息去重策略，以提高历史分页的连续性。[1]

## 使用方式

安装 `TelegramSearchNative-v0.6.0-scroll-pagination-fix-debug.apk` 后，可在消息详情页直接上下滚动浏览完整内容。在**同步**页面选择会话并启动历史同步，页面将显示扫描进度、索引数量和同步状态。

## 访问范围

已存在的本地消息不会重复写入，因此新增文本索引数量可为零。消息历史的实际可访问范围由 Telegram 服务端、会话权限和内容保护策略决定。
