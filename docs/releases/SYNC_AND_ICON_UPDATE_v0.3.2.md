# Telegram Search Native v0.3.2：同步、索引与图标更新

v0.3.2 提升了会话信息加载与历史分页同步的稳定性，并扩展本地索引范围至媒体消息的文字说明。

## 功能更新

| 模块 | 更新内容 |
|---|---|
| 会话标题加载 | 会话标题尚未就绪时显示加载占位名称，并主动获取会话详情补全标题。 |
| 历史分页同步 | 按消息游标持续读取更早历史，不以单页数量作为同步完成条件。 |
| 本地去重 | 按会话 ID 与消息 ID 去重，避免重复索引和重复搜索结果。 |
| 媒体文字索引 | 图片、视频、动画、文件、音频和语音消息的 caption 可进入本地索引。 |
| 搜索结果 | 移除固定显示数量限制，展示已同步的全部匹配结果。 |
| 启动图标 | 更新为深靛蓝对话检索主题图标，适配各 Android 屏幕密度。 |

## 同步与检索

安装 `TelegramSearchNative-v0.3.2-sync-icon-debug.apk` 后，在**同步**页面重新选择目标会话并启动全量历史同步。同步状态显示当前会话、扫描消息数量和新增文本索引数量；任务可在当前页完成后停止。

本地索引保存文本消息与带文字说明的媒体消息。纯媒体二进制内容不会下载或写入搜索数据库，因此索引数量可能低于会话总消息数量。

## 数据边界

应用仅保存当前账号可访问的可索引文本内容，历史访问范围受 Telegram 服务端、会话权限和内容保护策略限制。
