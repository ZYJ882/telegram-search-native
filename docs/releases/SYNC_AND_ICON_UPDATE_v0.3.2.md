# Telegram Search Native v0.3.2：同步、索引与图标更新

## 你截图中发生了什么

| 截图现象 | 原因 | v0.3.2 的修复 |
|---|---|---|
| 多个复选框后面没有聊天名称 | TDLib 先推送了会话列表项目，但部分会话标题尚未写入本地 UI 状态。 | 空标题现在会显示“会话 <编号>（正在载入名称）”，并主动请求该会话详情来补取标题，不再显示空白行。 |
| 第一次显示“扫描 1 条”，再点几次才显示“扫描 100 条” | 旧同步逻辑错误地把一次返回页的计数当作历史是否结束的判断条件；TDLib 的页级返回数量不能这样使用。 | 新逻辑仅在“最旧消息游标无法继续向前移动”或服务器不再返回消息时结束，会持续向更早的历史分页。 |
| “新增 0 条文本索引” | 本次扫描到的可索引文字已经存在于手机数据库，或该页都是无文字媒体/服务消息。数据库会按 `会话 + 消息 ID` 去重。 | 保留去重以避免重复搜索结果；新增版本同时索引图片、视频、动画、文件、音频和语音消息的**文字说明（caption）**。 |
| 搜索页只有 12 条 | 那是此前已经写入本机的 12 条文本索引，并非频道历史总数。 | 搜索结果不再设置 250 条显示上限；完整历史同步结束后会展示全部已索引文本。 |

## 新图标

新版内置新的深靛蓝“对话气泡 + 放大镜”启动图标。它不使用 Telegram 官方纸飞机标志，表达的是“本机对话检索”。各 Android 屏幕密度图标均已打入 APK。

## 升级与同步步骤

1. 下载并直接安装 `TelegramSearchNative-v0.3.2-sync-icon-debug.apk` 覆盖旧版。**不要先卸载旧版**，这样会尽量保留当前设备上的 API 参数、登录会话和已建立索引。
2. 打开新版后，进入 **同步**。由于会话勾选状态不会跨 App 重启保留，请重新勾选目标频道。
3. 点击 **同步所选会话全部历史** 一次，然后等待。同步中会显示当前会话、已扫描消息数和新增文本索引数。
4. 不要连续重复点击按钮。需要停止时，点击 **完成当前页后取消同步**；当前页写入完成后会安全停止。
5. 页面出现“同步完成”后，打开 **搜索**。先留空关键词查看本机全部索引数量，再输入关键词检索。

> 对于存在大量图片、视频、贴纸或无文字动态的频道，搜索索引总数仍可能少于频道总消息数。这是正常的：检索库保存文字消息和带文字说明的媒体消息，而不会把纯媒体二进制文件下载到手机。

## 验收方式

若该频道确实有较早的文字内容，同步过程中“已扫描”应从 100 继续增长为 200、300……，而不是在 100 停止；“新增文本索引”会随发现旧文字或媒体说明逐步增加。若扫描很快结束且新增仍为 0，说明该频道当前可访问的历史中没有尚未入库的可索引文字，或此前已被完整索引。

请不要发送 `api_hash`、验证码、两步验证密码或 TDLib 数据目录。若问题仍存在，请提供同步页的错误文字，或仅遮挡隐私字段后的截图。
