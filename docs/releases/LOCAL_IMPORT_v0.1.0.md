# Telegram Search Local v0.1.0：本地导入与离线检索

v0.1.0 是 Telegram Search Native 的本地导入版本，面向 Telegram 聊天导出文件的设备内索引和关键词检索场景。

## 功能

| 功能 | 说明 |
|---|---|
| JSON / JSONL 导入 | 支持 Telegram Desktop `result.json`、常见单会话 JSON 与 JSONL 文本记录。 |
| 本地 SQLite 索引 | 导入的文本消息、会话名称、发送者和时间写入应用私有数据库。 |
| 关键词检索 | 支持关键词匹配、会话过滤、日期范围筛选与结果高亮。 |
| 本机书签 | 可在本地索引中标记和查看重要消息。 |
| 数据清除 | 可清除应用内已建立的索引和书签。 |

## 隐私范围

该版本不包含 Telegram 账号登录、网络同步或云端服务。应用仅处理用户通过系统文件选择器主动导入的本地文本文件。

## 构建信息

最低 Android 版本为 API 26。APK 为调试签名构建，用于本地安装与功能体验。
