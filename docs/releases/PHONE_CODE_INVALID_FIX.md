# Telegram Search Native v0.2.1：验证码错误恢复

v0.2.1 完善了 TDLib 登录状态机中的验证码错误处理，为常见授权状态提供更清晰的本地提示和恢复路径。

## 认证状态处理

| 状态 | 说明 |
|---|---|
| `PHONE_CODE_INVALID` | 验证码与当前登录请求不匹配。 |
| `PHONE_CODE_EXPIRED` | 验证码已过期，需要重新发起登录请求。 |
| `PHONE_NUMBER_INVALID` | 手机号格式不符合 Telegram 要求。 |
| 两步验证 | 在账号启用两步验证时，认证流程自动切换为密码输入。 |

## 功能更新

应用将 `PHONE_CODE_INVALID` 识别为明确的验证码错误状态，并提供重新开始登录的入口。验证码输入框在错误后自动清空；认证页面同时为常见手机号、验证码与两步验证状态提供中文说明。

## 使用方式

安装 `TelegramSearchNative-v0.2.1-code-retry-debug.apk` 后，在**连接**页面输入带国家或地区码的手机号，并提交当前登录请求对应的有效验证码。若账号启用两步验证，按页面提示输入两步验证密码。

## 安全边界

验证码、两步验证密码、API ID、API Hash 和 TDLib 工作目录均不应公开或共享。认证信息仅在设备内的 Telegram 登录流程中使用。
