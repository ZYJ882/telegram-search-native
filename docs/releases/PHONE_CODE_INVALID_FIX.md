# `PHONE_CODE_INVALID`：原因与安全重试方法

## 这是什么意思

`PHONE_CODE_INVALID` 是 Telegram/TDLib 返回的状态，表示本次登录流程提交的**验证码不匹配**。它通常不表示 API ID 或 API Hash 配置错误，也不代表账号被永久封禁。

| 常见原因 | 说明 |
|---|---|
| 输入了旧验证码 | 重新请求、重新初始化或更换登录流程后，前一次验证码会失效。 |
| 验证码抄错 | 多输/少输数字，或误把其他登录流程的验证码填入。 |
| 代码已过期 | 等待时间过长后，Telegram 不再接受该验证码。 |
| 多个登录流程并行 | 同时在网页、官方 Telegram 和本 App 反复登录，会使人难以判断哪一条是最新验证码。 |

## 当前已安装版本的立即处理办法

你的截图是旧版本的失败界面。请按以下步骤操作：

1. 点击 **重新初始化**。
2. 等待页面出现 **输入手机号**，再次输入含国家/地区码的手机号，例如 `+86…`。
3. 点击发送登录请求后，等待 Telegram 针对**这一次请求**发送的最新验证码。
4. 只输入最新一条验证码一次；不要输入先前网页登录、其他 App 登录或旧通知中的验证码。
5. 如果账号启用两步验证，页面会改为要求两步验证密码；此时不要再填验证码。

验证码和两步验证密码只能直接填在手机 App 页面，不能发送到聊天中。

## 更新版 APK：v0.2.1-code-retry

本次修复后，应用会将 `PHONE_CODE_INVALID` 识别为“验证码无效”，而不是笼统显示“连接失败”。验证码输入框会在错误后自动清空，并提供：

- 中文原因说明；
- **验证码无效或过期？重新开始登录** 按钮；
- 对 `PHONE_CODE_EXPIRED`、`PHONE_NUMBER_INVALID` 的单独中文提示；
- 更准确的本地数据保护文字。

建议安装更新版后再重试。安装同包名更新版通常会保留你已在设备内保存的 API ID 和 API Hash；如果 Android 弹出更新/安装提示，请按系统提示确认。不要卸载旧 App，除非你接受清除其中的本地会话和索引数据。

## 仍然失败时

请停止连续请求验证码，等待一段时间后仅发起一次新的登录。若仍失败，请提供错误代码（例如 `PHONE_CODE_EXPIRED`、`FLOOD_WAIT_X`）或已遮挡的截图；不要发送任何手机号、验证码、两步验证密码、API Hash 或应用数据文件。
