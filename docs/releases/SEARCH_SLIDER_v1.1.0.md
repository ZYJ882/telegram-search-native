# Telegram Search Native v1.1.0：搜索页垂直滑块定位

v1.1.0 移除搜索页右侧密集字母列，改为垂直滑块快速定位控件。

## 功能更新

| 项目 | 说明 |
|---|---|
| 垂直滑块 | 右侧显示细轨道与圆形滑块，不再显示密集的 #–Z 字母列。 |
| 宽触摸热区 | 滑块视觉轨道保持紧凑，触摸区域扩展为 48dp 宽度，便于单手拖动。 |
| 实时定位 | 按住或拖动滑块时，根据纵向比例直接定位到搜索结果列表的对应位置。 |
| 进度浮层 | 拖动期间显示当前列表位置百分比，松开后自动隐藏。 |
| 直接跳转 | 使用无动画的列表项定位，避免快速拖动时的滚动动画堆积。 |
| 滑块跟随 | 正常上下滚动搜索列表时，滑块位置会同步反映当前浏览进度。 |

## 使用方式

在搜索结果页右侧的圆形滑块或其附近区域按住并上下拖动。滑块将跟随手指移动，列表同步定位；浮层显示当前进度。无需再在字母区内选择字符。
