# Telegram Search Native v0.4.0：会话搜索与选择管理

v0.4.0 优化同步范围的选择流程，为会话较多的账号提供名称检索、已选会话置顶与同步前确认能力。

## 功能更新

| 功能 | 说明 |
|---|---|
| 会话名称搜索 | 支持按频道、群组或私聊名称进行部分匹配检索；英文名称不区分大小写。 |
| 已选会话计数 | 同步页显示当前已选会话数量，便于确认同步范围。 |
| 已选会话置顶 | 已勾选会话固定显示在列表顶部，不受搜索关键词影响。 |
| 自动定位 | 从搜索结果勾选会话后，列表自动回到已选会话区域。 |
| 搜索清除 | 可一键清空搜索条件并恢复未选会话列表。 |

## 使用方式

安装 `TelegramSearchNative-v0.4.0-chat-picker-debug.apk` 后，进入**同步**页面，按名称检索并勾选需要同步的会话。确认顶部已选列表和计数后，启动“同步已选会话的全部历史”。同步运行期间，会话选择将保持锁定，以确保同步队列稳定。

## 状态范围

会话勾选状态在当前应用运行期间有效。重新启动应用、重新登录或升级版本后，建议在同步页面重新确认同步范围。
