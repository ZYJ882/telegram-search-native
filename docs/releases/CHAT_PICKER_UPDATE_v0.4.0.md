# Telegram Search Native v0.4.0：会话搜索与已选置顶

## 新增功能

同步页面新增了会话名称搜索框和已选会话管理能力，适合会话数量较多时选择需要导出的频道或群组。

| 功能 | 使用方式 | 行为 |
|---|---|---|
| 搜索会话名称 | 在“搜索会话名称”输入频道、群组或私聊名称的部分文字。 | 未选会话会按名称筛选；搜索不区分英文大小写。 |
| 已选计数 | 搜索框下方显示“已选 N 个会话”。 | 在开始同步前可快速确认选择数量。 |
| 已选置顶 | 勾选任一会话。 | 该会话立即移动至列表顶部的“已选会话（置顶）”区域。 |
| 自动回到顶部 | 从搜索结果中勾选会话。 | 列表会自动滚动回顶部，方便查看刚刚选中的会话。 |
| 保留已选可见 | 输入新的搜索词后。 | 已选会话仍始终显示在顶部，不会因为搜索词不匹配而消失。 |
| 清除搜索 | 点击搜索框右侧的关闭图标。 | 清空关键词，重新显示全部未选会话。 |

## 使用步骤

1. 安装 `TelegramSearchNative-v0.4.0-chat-picker-debug.apk` 覆盖旧版本；不要卸载旧 App。
2. 打开 **同步** 页，在“搜索会话名称”中输入目标频道或群组名。
3. 勾选会话后，确认它已移动到顶部“已选会话（置顶）”区域。
4. 继续搜索并勾选其他会话；顶部计数会自动变化。
5. 确认无误后点击“同步已选 N 个会话的全部历史”。同步进行时，会话选择会被暂时锁定，防止同步队列变动。

> 会话勾选状态是本次 App 运行期间的选择状态。升级、重新启动 App 或重新登录后，请在同步页重新确认并勾选需要导出的会话。
