# Telegram Search Native v0.9.1：右侧索引条拖动修复

v0.9.1 修复搜索页右侧字母索引条在部分设备上无法通过上下滑动切换分组的问题。

## 修复内容

| 项目 | 说明 |
|---|---|
| 拖动手势 | 索引条改用通用拖动手势处理，触摸开始后可持续接收上下移动位置。 |
| 分组命中 | 手指位置会映射到最近的有效 `#–Z` 分组；无数据字母会自动跳过。 |
| 即时定位 | 每次进入新的有效分组时，搜索列表立即跳转至对应分组标题。 |
| 点击定位 | 保留对单个字母的点击定位。 |

## 使用方式

在搜索结果页右侧索引条内按住并上下滑动。列表会随手指经过的有效字母分组即时切换；松开手指后保留在当前分组。点击单个有效字母同样可以定位。
