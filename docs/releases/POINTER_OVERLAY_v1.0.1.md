# Telegram Search Native v1.0.1：字母区连续触摸修复

v1.0.1 针对搜索页右侧字母区在部分设备上无法稳定响应长按和上下滑动的问题，改用覆盖层原始指针事件追踪。

## 修复内容

| 项目 | 说明 |
|---|---|
| 连续触摸追踪 | 字母区直接监听按下、移动与释放事件，不再依赖拖动手势识别阈值。 |
| 首次按下命中 | 手指按到字母区后立即计算对应分组。 |
| 连续位置更新 | 手指在字母区内上下移动时，持续依据纵向位置切换最近的有效分组。 |
| 触摸接管 | 索引区域在触摸期间消费自身事件，避免子级点击组件截获滑动序列。 |
| 浮层状态 | 按住时显示当前字母浮层，手指释放时自动隐藏。 |

## 使用方式

在搜索结果页右侧细小字母列上按住并上下移动。无需等待长按阈值；列表会随手指位置切换到对应有效分组，浮层显示当前字母。松开后浮层隐藏。
