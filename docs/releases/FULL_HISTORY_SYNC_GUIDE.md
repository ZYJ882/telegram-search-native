# Telegram Search Native v0.3.0：全量历史同步

v0.3.0 引入按会话顺序执行的历史分页同步。已选择的频道、群组和私聊可从最新消息开始，持续向更早历史读取并建立设备内文本索引。

## 功能更新

| 功能 | 说明 |
|---|---|
| 历史分页读取 | 每页读取最多 100 条消息，并持续向更早的历史推进。 |
| 同步进度 | 显示当前会话、扫描消息数量、近似总数和新增文本索引数量。 |
| 安全停止 | 支持在当前页完成写入后停止同步。 |
| 本地去重 | 按 `chat_id + remote_id` 去重，重复同步不产生重复搜索结果。 |
| 多会话队列 | 多个已选会话按顺序依次同步。 |

## 使用方式

安装 `TelegramSearchNative-v0.3.0-full-history-debug.apk` 后，进入**同步**页面选择目标会话并启动“同步所选会话全部历史”。完成后可在**搜索**页面对本地索引内容进行关键词检索。

## 索引范围

该版本索引可检索的文本消息。纯媒体消息、贴纸、服务消息、无文字转发内容及当前账号不可访问的历史内容不会写入搜索数据库。TDLib 返回的 `total_count` 为近似数量，用于同步进度参考。

## 运行边界

历史访问范围受 Telegram 服务端、账号权限和会话可见性限制。同步过程中建议保持网络连接稳定，应用数据、开发者参数和登录凭据仅保留在设备本地。
