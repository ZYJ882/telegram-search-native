# Telegram Search Native v0.8.0：本地数据管理与本机收藏夹

v0.8.0 增加本地索引管理与本机收藏夹，便于整理已同步或导入的消息内容。

## 功能更新

| 功能 | 说明 |
|---|---|
| 本机收藏夹 | 导航栏新增“收藏”入口，集中显示已标记的本地消息。 |
| 收藏状态 | 搜索结果和消息详情均可通过书签图标加入或移除本机收藏。 |
| 收藏计数 | 搜索页与设置页显示当前本机收藏数量。 |
| 单条删除 | 消息详情可将指定消息从本地索引删除。 |
| 清除本地数据 | 设置页提供确认弹窗，可一次清除本机消息、搜索索引和本机收藏。 |

## 数据范围

本机收藏与 Telegram Saved Messages 相互独立。本机收藏仅保存在当前设备的应用 SQLite 索引中，不会向 Telegram 账号发送任何消息。

单条删除和清除本地数据仅影响当前设备内的搜索索引、收藏标记和同步消息；Telegram 账号中的原始聊天、频道消息和 Saved Messages 不会受到影响。

## 使用方式

在搜索结果或消息详情点击书签图标，即可加入或移出**本机收藏**。在底部导航栏打开**收藏**，可以查看全部已收藏消息。需要删除某条本地记录时，在消息详情选择“从本机索引删除”；需要一次清除全部本地数据时，在**设置 → 本地数据**选择“清除本地数据”。
