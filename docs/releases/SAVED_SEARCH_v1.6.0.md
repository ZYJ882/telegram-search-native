# Telegram Search Native v1.6.0：本机收藏搜索

v1.6.0 为“本机收藏”页面加入与主搜索页一致的多关键词本地搜索能力，方便在大量收藏消息中快速找到需要的内容。

## 功能更新

| 项目 | 说明 |
|---|---|
| 收藏搜索框 | 收藏页顶部新增“搜索本机收藏”输入框。 |
| 多关键词匹配 | 支持空格、逗号、顿号、分号、竖线或斜杠分隔关键词；结果必须同时包含全部关键词。 |
| 收藏范围限定 | 仅检索当前设备本地索引中已收藏的消息，不读取、上传或修改 Telegram 账号收藏。 |
| 快速清除 | 输入内容后显示清除按钮，可一键恢复全部本机收藏。 |
| 结果反馈 | 显示当前搜索结果数量；没有匹配内容时提供独立提示。 |
| 快速定位 | 右侧垂直滑块基于当前筛选结果快速跳转；修改关键词后自动回到列表顶部。 |

## 使用方式

进入“收藏”标签，在顶部输入关键词即可筛选。例如输入 `漫画 中文字幕`，只显示本机收藏中同时包含“漫画”和“中文字幕”的消息；使用逗号、顿号等分隔符也可得到相同效果。

本版本可以直接覆盖安装旧版，现有本机索引、收藏、登录状态和设备内 API 设置都会保留。
