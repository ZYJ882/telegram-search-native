# Telegram Search Native v1.3.0：搜索结果多选操作

v1.3.0 为搜索结果页加入长按多选模式，支持全选、批量本机收藏和批量删除本地索引。

## 功能更新

| 项目 | 说明 |
|---|---|
| 长按多选 | 长按任意搜索结果即可进入多选模式；消息卡片显示勾选状态。 |
| 逐条勾选 | 多选模式下点击消息卡片可选中或取消选中该条消息。 |
| 全选与取消全选 | 顶部操作条可一次选中当前搜索结果中的全部消息，也可取消全部选择。 |
| 批量本机收藏 | 可将已选消息一次加入本机收藏夹。收藏仅保存在当前设备。 |
| 批量删除索引 | 可批量从本机索引删除已选消息，操作前需要确认。 |
| 退出方式 | 点击顶部关闭按钮或使用系统返回键即可退出多选模式。 |
| 数据范围 | 批量收藏和删除只影响本应用在当前设备保存的索引数据，不会修改 Telegram 账号中的原始消息或 Saved Messages。 |

## 使用方式

在搜索结果页长按一条消息。进入多选模式后，可点击更多消息进行勾选，或使用顶部“全选”按钮。随后可点击书签图标加入本机收藏，或点击删除图标删除本机索引。
