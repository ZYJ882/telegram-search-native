# Telegram Search Native v1.0.0：抽屉式字母索引与滚动优化

v1.0.0 重构搜索页右侧字母索引，采用紧凑的抽屉式长按滑动交互，并优化搜索结果滚动时的计算开销。

## 功能更新

| 项目 | 说明 |
|---|---|
| 紧凑字母列 | 右侧索引缩窄为细小的 `#–Z` 字母列，减少对搜索结果阅读区域的遮挡。 |
| 长按滑动 | 在字母列内长按后上下滑动，按手指位置选择最近的有效分组。 |
| 当前字母浮层 | 长按滑动期间显示当前命中的大字母浮层，松开后自动隐藏。 |
| 非动画定位 | 分组跳转使用直接定位，避免拖动过程中持续启动列表动画。 |
| 分组缓存 | 搜索结果的会话分组、排序和目标位置在结果变化时才重新计算，降低普通列表滑动时的重组开销。 |
| 点击定位 | 单击有效字母仍可直接跳转至对应分组。 |

## 使用方式

在搜索结果页右侧的细小字母列上**长按**，再上下滑动。中间会显示当前选中的大字母，列表会立即定位到对应分组。名称不以英文字母开头的会话归入 `#` 分组。
