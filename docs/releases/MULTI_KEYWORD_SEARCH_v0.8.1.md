# Telegram Search Native v0.8.1：多关键词包含检索

v0.8.1 扩展本地消息检索方式，支持在同一次搜索中输入多个关键词，并返回同时包含全部关键词的消息。

## 匹配规则

| 输入方式 | 示例 | 匹配结果 |
|---|---|---|
| 单个关键词 | `登录` | 返回包含“登录”的消息。 |
| 空格分隔 | `登录 验证码` | 返回同时包含“登录”和“验证码”的消息。 |
| 常见分隔符 | `登录，验证码`、`登录；验证码`、`登录/验证码` | 与空格分隔效果相同。 |
| 重复关键词 | `登录 登录` | 自动合并重复词，不影响匹配结果。 |

支持的分隔符包括空格、逗号、中文逗号、顿号、分号、中文分号、竖线和斜杠。

## 使用方式

在**搜索**页面的关键词输入框中，使用任意支持的分隔符输入多个词。应用会对每个词独立匹配，并仅显示同时满足全部关键词条件的本地消息。单个连续关键词的检索方式保持不变。
